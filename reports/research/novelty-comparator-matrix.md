# Novelty Comparator Matrix

Status: complete internal challenge for D02 on 2026-09-11 UTC  
Evidence base: `source-verification-register.json` and primary-source links below

## Decision

The project is not justified as the first or only system for emergent communication,
causal listening analysis, learned non-text carriers, reproducible machine-learning
workflows, append-only transparency, or cross-partner evaluation. Each component has
clear prior art. The defensible candidate contribution is narrower:

> Evaluate whether outcome-blind, contemporaneous private semantic ledgers add
> predictive and audit value beyond transcripts, task outcomes, policy-state
> readouts, ordinary logs, and signed logs in controlled emergent-communication
> studies, while preserving causal interventions and independently verifiable run
> provenance.

That statement is a research question until the registered comparisons are executed.
Even if supported, novelty would concern the evaluated integration and incremental
value in this setting—not ownership of any component.

## Explicitly rejected claims

- “First auditable emergent-communication laboratory.” The search did not establish
  priority, and “auditable” is too underspecified for a defensible first claim.
- “Unique causal ledger.” Private semantic histories, explicit dialogue histories,
  policy readouts, causal communication metrics, signed logs, and transparency logs
  each have adjacent prior art. Only incremental predictive/audit value is testable.
- “Agents invent both signs and meanings” from a random fixed private codebook.
  Invention requires observed acquisition, modification, reuse, and partner learning.
- “Tamper evidence guarantees truth.” Integrity can detect specified mutations after
  commitment; it cannot establish semantic honesty, complete pre-commit capture,
  event-time accuracy, or signer independence by itself.
- “No leakage” from failed probes. The defensible result is a powered upper bound in
  a declared threat model with detector-positive controls.
- “Human-like” or developmental equivalence from a nursery metaphor, staged
  curriculum, structure score, or pretrained language-model behavior.

## Claim gate

D02 is complete for protocol design: unsupported priority wording is prohibited and
the closest-component matrix is source-backed. It is not a positive novelty finding.
Before submission, repeat the search to the manuscript-freeze date, inspect current
toolkit repositories and newly published work, and obtain independent citation
review. Any overlap found then narrows the claim; it does not justify suppressing a
comparator.
